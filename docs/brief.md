# DayMate M1.1

DayMate 是一个轻陪伴式“工作方式观察”产品。

用户每天偶尔遇见一位班友，看见对方如何以另一种方式度过同一段工作时间。班友是人物角色；职业是背景；工作方式是产品主要内容。

## 当前示例

- 班友：数字游民
- 职业背景：远程产品设计师

## 本阶段范围

- 两个页面：今日班友、班友图鉴
- 一个轻互动：提问
- 点击“你想知道什么吗？”后显示磨砂输入框；按 Enter 或点击发送，班友用预设文字回应
- 不支持拖拽；输入内容仅用于本地演示，不保存
- 点击班友姓名旁的信息按钮，显示职业信息；3 秒后以泡泡爆开形式消失

## 暂不实现

- 本地时间切换
- localStorage 自动收藏
- 正式场景插画
- 登录、后端、数据库、外部 API
- 真实 AI 对话、聊天记录和宠物养成数值
